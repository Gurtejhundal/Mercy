# Mercy v1.0

*that one teacher we all know*

Mercy's first stable release: a source-grounded codebase teacher and viva coach inside Codex or Claude Code, with a local Python evidence toolkit and a self-contained study notebook.

## Included

- Native Codex and Claude Code skills for focused investigation, reviewed notebooks and one-question-at-a-time viva practice.
- Bounded, numbered source context and fingerprint-checked, atomic answer reviews.
- An offline black-and-white notebook with Mind Map as the opening view, import graph, directory atlas, reference trails and searchable viva questions.
- Editable evidence JSON and a Markdown text companion; PDF generation remains optional.
- The supplied teacher artwork, notebook website and illustrated README.

## Install

Requires Python 3.10+. Download the wheel below, then run:

```bash
python3 -m pip install mercy_viva-1.0.0-py3-none-any.whl
mercy install --project /path/to/your/project --platform both
```

In Codex use `$mercy`; in Claude Code use `/mercy`. Start a new host session if the installed skill is not yet discovered. The native workflow uses your host model and needs no separate model service or provider key.

## Downloads

- `.whl`: installable Python package, including native skills, notebook font and teacher artwork.
- `.tar.gz`: Python source distribution.
- `mercy-studio.html`: standalone example notebook generated from the included mini-rag fixture. Download and open it in your browser.
- `SHA256SUMS.txt`: checksums for these three artifacts.
