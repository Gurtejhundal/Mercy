# Mercy v1.0.3

Keeps generated artifacts out of the source map: skip `output`, `outputs`, collected Django `staticfiles`, `test-results` and `playwright-report` directories. Historical checkout snapshots and copied assets in those directories no longer inflate route, import or framework clues.

Includes v1.0.2's immediate bare-invocation workflow, project-specific notebook review requirements, Django URL pattern detection and Next.js false-positive correction.

Update the marketplace/plugin and start a new host session. Analysis remains static and bounded. Skipped directory names are discovery heuristics, not proof about project architecture; if a project deliberately keeps hand-written source there, review it separately.
