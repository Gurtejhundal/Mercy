# Mercy v1.0.5

Project Overview becomes the starting point for short, source-grounded viva answers while preserving Mercy’s marker notebook style.

- Remove the Demo section; preserve existing reviewed demonstration records in editable JSON.
- Add overview questions covering relevant data/model origins, training versus inference, parameters, formulas, evaluation, fundamentals, users and output. Unknowns remain explicit; resources link to authoritative proof.
- Open architecture at the whole-system view, with validated, cited component relationships including HTTP. Retain labelled import-only fallback for older reports.
- Add opt-in redacted code previews with source-fingerprint checks. Explorer and citation links open the selected file and highlight its line; source stays inert and private reports stay local.
- Add brief transitions with reduced-motion support. Keep native scrolling and Ctrl-wheel/pinch diagram zoom.

Source inspection does not certify application behavior, model accuracy or live provider access. Source redaction is best-effort; review reports before sharing.
