# Mercy v1.0.4

The report returns to Mercy’s marker notebook: handwritten headings, paper, ink rules and one violet accent.

- Project Overview replaces Project Guide, showing frontend/backend locations, model origin/download sources, bundled technology logos and resource links.
- Folders becomes a nested explorer with a plain-language explanation on the right. Source citations open parent folders and select the cited file.
- Architecture focuses on one component and its direct resolved imports, avoiding a wall of crossing links.
- Short viva answers, demonstrations and source-traced user flowcharts remain. Existing evidence can still be edited and regenerated; missing new metadata stays explicitly unreviewed.
- New reviewed fields validate file explanations, indexed technology locations, model origins, logo slugs and safe HTTPS resources.
- The installed-wheel check now generates an offline report to verify its packaged assets.

The example notebooks contain source walkthroughs, not proof of an executed application, model training or live provider access. Resource links only open when selected; logos and report assets are embedded for offline reading.
