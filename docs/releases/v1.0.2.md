# Mercy v1.0.2

- A bare Mercy invocation explicitly starts repository investigation and notebook generation immediately, without requesting a second prompt or presenting a menu.
- Notebook review instructions require project-specific coverage, useful citations, plain-language explanations and explicit uncertainties instead of a generic starter bank.
- Detect Django literal URL patterns, including import aliases, multiline calls, regular expressions and empty patterns, without importing or executing the target application.
- Display route counts as route clues and label Django patterns as local to their URL files. Mounted prefixes are not combined or claimed as verified endpoints.
- Stop treating ordinary `next()` calls and redirect parameters as Next.js framework evidence.

Update the marketplace/plugin and start a new host session. Python 3.10+ remains required. The host model performs the investigation; the local CLI alone generates deterministic starter evidence. No target app, database, tests or external service is run automatically.
