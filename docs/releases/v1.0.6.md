# Mercy v1.0.6

Fresh scans and regenerated evidence use the current notebook system without editing a customer report by hand.

- Bare Mercy invocation generates or resumes the reviewed HTML notebook, including after an earlier overview discussion. Existing reports are re-rendered through the bundled toolkit before delivery.
- Guided drafts select overview questions by default. Older evidence without presentation flags receives a compact overview; explicit selections remain respected.
- Reports record and display their generator version. `mercy --version` identifies the active toolkit to catch outdated installations.
- Invocation prompts consistently request the HTML artifact and its file link. Detailed edited answers remain preserved during regeneration.
- Regression checks cover fresh generation, legacy evidence, current report navigation and the bundled launcher running outside the Mercy checkout.

These changes do not verify application runtime behavior or model accuracy. Local browser pixels and physical input remain unverified.
